# 🧪 Portfólio de Quality Assurance (QA)

     Repositório dedicado à documentação de planos de testes, cenários escritos em BDD (Gherkin) e boas práticas de engenharia de qualidade.

     ## 🛠️ Tecnologias e Ferramentas
     * **Controle de Versão:** Git & GitHub
     * **Especificação:** BDD / Gherkin
     * **Documentação:** Markdown

     ## 📂 Estrutura do Projeto
     * `docs/` — Planos de testes e checklists funcionais.
     * `features/` — Cenários de comportamento em Gherkin.
